GameSaloon

The game server for web games, that you can read and host.

The handshake and lobby layer: rooms, WebRTC signaling, an action relay, Elo matchmaking and identity over one WebSocket. A small Node/TypeScript module with a single runtime dependency.

Get started Read the docs Try the hosted version

What it does

Rooms

Short room codes, public listing and private rooms, up to 8 machines per room and 4 local players per machine.

WebRTC signaling

Forwards offers, answers and ICE candidates, and hands out ICE servers with short-lived TURN credentials.

Action relay

Sequenced actions with acks and resume tokens for games that want the server in the loop.

Quick and ranked queues

Ranked pairs within a rating window that widens with wait time.

Elo ratings

Placement games, a decreasing K factor and tiers from Bronze to Master.

Pluggable store

A Promise-based PlayerStore interface with an in-memory implementation and a contract test suite, for the day you connect your own database.

It does not run your game logic and does not ship an account system: you plug in identity verification.

Three ways to use it

Lobby only

Memory store, zero setup. Rooms, relay, matchmaking and Elo. Nothing is persisted, and the economy and online-data services have no data in this mode.

Bring your own database

Want an economy, cloud saves or achievements? Connect your own database through the PlayerStore / TableApi contract. Today the shipped HTTP store targets a CRM-style table API; a ready-made generic SQL adapter is not shipped yet.

Use Etcito (hosted)

Economy, saves, achievements, payments and creator tooling, operated for you by the team behind GameSaloon.

Quickstart

git clone https://github.com/Etcito/gamesaloon.git && cd gamesaloon
npm install --omit=dev
npm start
# listening on 127.0.0.1:8787  (GET /health, WebSocket on /ws)

Requires Node 22.18 or newer. Full walkthrough in docs/quickstart.md.
